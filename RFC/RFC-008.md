## 1. Abstract & Architectural Objective
`RFC-008` specifies a self-contained, zero-weight (`0 MB` local LLM weights) Python reference toolkit (`rfc008_toolkit.py`) designed to execute the cryptographic provenance, deterministic verification gates (`RFC-007`), and enclosure latency geometry (`RFC-006`) on constrained `ARM64` edge devices.

By strictly separating **untrusted probabilistic inference** from **deterministic CPU verification**, human rights defenders and independent researchers can audit legal and administrative records offline without requiring cloud APIs, GPU acceleration, or heavy database daemons.

## 2. Mathematical & Computational Formalization

### 2.1 Pre-LLM Cryptographic Provenance (`RFC-007` Layer 1)
Let an evidentiary document $D$ be represented as an ordered byte sequence $B \in \{0,1\}^*$. Prior to any parsing or inference, the ingestion boundary computes a cryptographic commitment using `SHA-256` ($H : \{0,1\}^* \to \{0,1\}^{256}$):

$$h_D = H(B)$$

After deterministic text extraction $\mathcal{E}(B) = T$ (where $T$ is a normalized UTF-8 string of length $|T|$), $T$ is partitioned into $n$ deterministic spans $C = \{c_0, c_1, \dots, c_{n-1}\}$. Each chunk $c_i$ is defined by half-open character offsets $[s_i, e_i)$ where $0 \le s_i < e_i \le |T|$ and substring $t_i = T[s_i : e_i]$, paired with its chunk digest:

$$h_{c_i} = H(\text{UTF8}(t_i))$$

The immutable **Source Manifest** $\mathcal{M}_D$ is sealed with a Merkle-like root commitment over the ordered tuple of chunk digests:

$$h_{\mathcal{M}} = H\left( h_D \parallel h_{c_0} \parallel h_{c_1} \parallel \dots \parallel h_{c_{n-1}} \right)$$

Any single-bit modification $B \to B'$ alters $h_D$ and $h_{\mathcal{M}}$ with collision probability $\approx 2^{-256}$, immediately invalidating downstream claims.

---

### 2.2 Deterministic Verification Gate (`RFC-007` Layer 2)
Let an LLM (or human annotator) emit a structured proposal tuple:

$$p = \langle \text{claim}, q, i, \tau_{\text{claimed}} \rangle$$

where:
* $q$ is the `exact_verbatim_quote`,
* $i \in \{0, \dots, n-1\}$ is the `claimed_chunk_id`, and
* $\tau_{\text{claimed}}$ is an ISO-8601 timestamp string.

The deterministic CPU gate $\mathcal{G}(p, \mathcal{M}_D) \to \{\texttt{VERIFIED}, \texttt{REJECTED}\}$ evaluates the conjunction of four boolean predicates:

$$\mathcal{G}(p, \mathcal{M}_D) = \mathbb{I}\Big( \underbrace{(0 \le i < n)}_{\text{Valid Index}} \land \underbrace{(H(\text{UTF8}(t_i)) = h_{c_i})}_{\text{Chunk Integrity}} \land \underbrace{(q \neq \varepsilon \land q \subseteq t_i)}_{\text{Exact Substring Match}} \land \underbrace{\mathcal{V}_{\text{ISO}}(\tau_{\text{claimed}})}_{\text{Temporal Validity}} \Big)$$

where $q \subseteq t_i$ denotes exact byte-for-byte substring inclusion (`q in t_i`), prohibiting fuzzy matching, paraphrasing, or semantic approximation at the admission boundary.

---

### 2.3 Active Inference Commit Seam (`Record ≠ Admit ≠ Commit`)
System state is partitioned into three strictly disjoint sets:
1. **$\mathcal{S}_{\text{Record}}$:** Raw artifacts and sealed manifests $\mathcal{M}_D$.
2. **$\mathcal{S}_{\text{Admit}}$:** Untrusted proposals $p$ emitted by probabilistic models.
3. **$\mathcal{S}_{\text{Commit}}$:** Verified facts admitted across the commit seam:

$$\mathcal{S}_{\text{Commit}} = \left\{ p \in \mathcal{S}_{\text{Admit}} \;\middle|\; \mathcal{G}(p, \mathcal{M}_D) = 1 \right\}$$

No causal edge or enclosure metric may be computed over elements in $\mathcal{S}_{\text{Admit}} \setminus \mathcal{S}_{\text{Commit}}$.

---

### 2.4 Institutional Enclosure Latency & Friction Geometry (`RFC-006`)
Given a sequence of committed procedural events $E = \langle e_0, e_1, \dots, e_k \rangle \subseteq \mathcal{S}_{\text{Commit}}$ ordered by verified timestamps $\tau_0 \le \tau_1 \le \dots \le \tau_k$:

* **Inter-Gate Latency ($\Delta \tau_j$):**
  $$\Delta \tau_j = \frac{\tau_j - \tau_{j-1}}{86400} \quad (\text{in days})$$
* **Deflection / Enclosure Ratio ($\rho_{\text{enc}}$):** For a case file with total procedural transitions $k$ and verified deflection/referral events $k_{\text{deflect}}$ (events returning a petitioner to a prior gate without substantive resolution):
  $$\rho_{\text{enc}} = \frac{k_{\text{deflect}}}{\max(1, k)} \in [0, 1]$$

"""
rfc008_toolkit.py
RFC-008 Edge-Sovereign Deterministic Verification & Enclosure Geometry Toolkit.
Zero external AI weights required. Designed for ARM64 / Termux execution.
"""

from __future__ import annotations

import hashlib
import json
from dataclasses import asdict, dataclass, field
from datetime import datetime
from enum import Enum
from pathlib import Path
from typing import List, Optional, Sequence

from pydantic import BaseModel, Field, ValidationError


# ==============================================================================
# 1. Cryptographic Primitives (RFC-007 Layer 1)
# ==============================================================================

def sha256_bytes(data: bytes) -> str:
    """Compute lowercase hexadecimal SHA-256 digest of raw bytes."""
    return hashlib.sha256(data).hexdigest()


def sha256_text(text: str) -> str:
    """Compute lowercase hexadecimal SHA-256 digest of UTF-8 encoded text."""
    return sha256_bytes(text.encode("utf-8"))


@dataclass(frozen=True)
class TextChunk:
    chunk_id: int
    start_offset: int
    end_offset: int
    text: str
    chunk_sha256: str


@dataclass(frozen=True)
class SourceManifest:
    source_filename: str
    raw_sha256: str
    byte_length: int
    chunk_size: int
    chunks: List[TextChunk]
    manifest_sha256: str


def build_source_manifest(
    raw_bytes: bytes,
    extracted_text: str,
    source_filename: str = "artifact.bin",
    chunk_size: int = 1200,
) -> SourceManifest:
    """
    Deterministically partition extracted text into fixed character spans
    and seal the raw artifact + chunk digests into an immutable manifest.
    """
    if chunk_size <= 0:
        raise ValueError("chunk_size must be a positive integer.")

    raw_hash = sha256_bytes(raw_bytes)
    chunks: List[TextChunk] = []

    for idx, start in enumerate(range(0, len(extracted_text), chunk_size)):
        end = min(start + chunk_size, len(extracted_text))
        span_text = extracted_text[start:end]
        chunks.append(
            TextChunk(
                chunk_id=idx,
                start_offset=start,
                end_offset=end,
                text=span_text,
                chunk_sha256=sha256_text(span_text),
            )
        )

    # Merkle-like root commitment: H(raw_sha256 || chunk_0_sha256 || ... || chunk_n_sha256)
    hasher = hashlib.sha256()
    hasher.update(raw_hash.encode("ascii"))
    for ch in chunks:
        hasher.update(ch.chunk_sha256.encode("ascii"))

    return SourceManifest(
        source_filename=source_filename,
        raw_sha256=raw_hash,
        byte_length=len(raw_bytes),
        chunk_size=chunk_size,
        chunks=chunks,
        manifest_sha256=hasher.hexdigest(),
    )


def verify_manifest_integrity(raw_bytes: bytes, manifest: SourceManifest) -> bool:
    """Re-verify raw bytes and chunk hashes against a sealed SourceManifest."""
    if sha256_bytes(raw_bytes) != manifest.raw_sha256:
        return False

    hasher = hashlib.sha256()
    hasher.update(manifest.raw_sha256.encode("ascii"))
    for ch in manifest.chunks:
        if sha256_text(ch.text) != ch.chunk_sha256:
            return False
        hasher.update(ch.chunk_sha256.encode("ascii"))

    return hasher.hexdigest() == manifest.manifest_sha256


# ==============================================================================
# 2. Schema-Bounded Proposal & Deterministic CPU Gate (RFC-007 Layer 2)
# ==============================================================================

class GateStatus(str, Enum):
    VERIFIED = "VERIFIED"
    SCHEMA_FAIL = "SCHEMA_FAIL"
    ORPHAN_CITATION = "ORPHAN_CITATION"
    CHUNK_TAMPERED = "CHUNK_TAMPERED"
    QUOTE_MISMATCH = "QUOTE_MISMATCH"
    INVALID_TIMESTAMP = "INVALID_TIMESTAMP"


class ClaimProposal(BaseModel):
Use code with caution.
"""Strict schema required from any probabilistic LLM extractor."""
claim_text: str = Field(..., min_length=1)
exact_verbatim_quote: str = Field(..., min_length=1)
claimed_chunk_id: int = Field(..., ge=0)
claimed_timestamp_iso: str = Field(..., min_length=10)
actor: str = Field(..., min_length=1)
is_deflection: bool = Field(default=False)
@dataclass(frozen=True)
class GateAuditResult:
status: GateStatus
proposal: Optional[ClaimProposal]
verified_chunk_sha256: Optional[str] = None
reason: str = ""
def parse_iso_timestamp(ts: str) -> Optional[datetime]:
"""Validate strict ISO-8601 date or datetime string."""
try:
# Handle trailing 'Z' for Python < 3.11 compatibility
normalized = ts.replace("Z", "+00:00")
return datetime.fromisoformat(normalized)
except ValueError:
return None
def verify_proposal_gate(
raw_proposal_json: str | dict,
manifest: SourceManifest,
) -> GateAuditResult:
"""
Deterministic CPU gate evaluating an untrusted LLM proposal against
a cryptographically sealed SourceManifest.
"""
# 1. Schema validation
try:
if isinstance(raw_proposal_json, str):
proposal = ClaimProposal.model_validate_json(raw_proposal_json)
else:
proposal = ClaimProposal.model_validate(raw_proposal_json)
except ValidationError as exc:
return GateAuditResult(
status=GateStatus.SCHEMA_FAIL,
proposal=None,
reason=f"Pydantic schema validation failed: {exc.error_count()} error(s).",
)
# 2. Chunk index bounds check
if proposal.claimed_chunk_id >= len(manifest.chunks):
return GateAuditResult(
status=GateStatus.ORPHAN_CITATION,
proposal=proposal,
reason=f"Chunk ID {proposal.claimed_chunk_id} out of bounds (max {len(manifest.chunks) - 1}).",
)
target_chunk = manifest.chunks[proposal.claimed_chunk_id]
# 3. Chunk cryptographic integrity check
if sha256_text(target_chunk.text) != target_chunk.chunk_sha256:
return GateAuditResult(
status=GateStatus.CHUNK_TAMPERED,
proposal=proposal,
reason="Chunk text digest does not match sealed manifest hash.",
)
# 4. Exact byte-for-byte substring match (zero fuzzy tolerance)
if proposal.exact_verbatim_quote not in target_chunk.text:
return GateAuditResult(
status=GateStatus.QUOTE_MISMATCH,
proposal=proposal,
reason="Verbatim quote not found byte-for-byte in target chunk.",
)
# 5. ISO-8601 temporal validity
if parse_iso_timestamp(proposal.claimed_timestamp_iso) is None:
return GateAuditResult(
status=GateStatus.INVALID_TIMESTAMP,
proposal=proposal,
reason=f"Invalid ISO-8601 timestamp: {proposal.claimed_timestamp_iso}",
)
return GateAuditResult(
status=GateStatus.VERIFIED,
proposal=proposal,
verified_chunk_sha256=target_chunk.chunk_sha256,
reason="Passed all deterministic CPU verification checks.",
)

@dataclass
class CommitSeamLedger:
"""
Enforces strict quarantine between raw records, untrusted proposals,
and committed causal facts.
"""
manifest: SourceManifest
admitted_quarantine: List[GateAuditResult] = field(default_factory=list)
committed_facts: List[GateAuditResult] = field(default_factory=list)
def submit_proposal(self, raw_proposal: str | dict) -> GateAuditResult:
audit = verify_proposal_gate(raw_proposal, self.manifest)
if audit.status == GateStatus.VERIFIED:
self.committed_facts.append(audit)
else:
self.admitted_quarantine.append(audit)
return audit

@dataclass(frozen=True)
class EnclosureMetrics:
total_committed_events: int
deflection_count: int
enclosure_ratio: float
inter_gate_latencies_days: List[float]
cumulative_latency_days: float
def compute_enclosure_geometry(committed_facts: Sequence[GateAuditResult]) -> EnclosureMetrics:
"""
Compute RFC-006 enclosure deflection ratio and inter-gate latency
exclusively from verified, committed facts.
"""
valid_events = [
item.proposal
for item in committed_facts
if item.status == GateStatus.VERIFIED and item.proposal is not None
]
if not valid_events:
return EnclosureMetrics(
total_committed_events=0,
deflection_count=0,
enclosure_ratio=0.0,
inter_gate_latencies_days=[],
cumulative_latency_days=0.0,
)
# Sort chronologically by verified ISO timestamp
sorted_events = sorted(
valid_events,
key=lambda p: parse_iso_timestamp(p.claimed_timestamp_iso),  # type: ignore[arg-type]
)
latencies: List[float] = []
for i in range(1, len(sorted_events)):
t_prev = parse_iso_timestamp(sorted_events[i - 1].claimed_timestamp_iso)
t_curr = parse_iso_timestamp(sorted_events[i].claimed_timestamp_iso)
assert t_prev is not None and t_curr is not None
delta_days = (t_curr - t_prev).total_seconds() / 86400.0
latencies.append(round(delta_days, 4))
deflections = sum(1 for e in sorted_events if e.is_deflection)
total = len(sorted_events)
ratio = round(deflections / max(1, total), 4)
return EnclosureMetrics(
total_committed_events=total,
deflection_count=deflections,
enclosure_ratio=ratio,
inter_gate_latencies_days=latencies,
cumulative_latency_days=round(sum(latencies), 4),
)
